<Aside type="note" title="Pre-1.0">
	agentsync is pre-1.0. Per [semantic versioning](https://semver.org/), the
	**interfaces** may still change in breaking ways before `v1.0.0` — both the
	programmatic API (Go package surface) and the CLI surface (commands and
	flags). The **core functionality** is considered **stable**: the three-state
	model, the canonical `~/.agentsync/` schema, and the apply/reconcile behavior
	are solid and safe to rely on. We avoid gratuitous interface churn and call
	out any breaking change in the [changelog](https://github.com/spxrogers/agentsync/blob/main/CHANGELOG.md).
</Aside>

## Package managers (recommended)

<Tabs syncKey="os">
	<TabItem label="macOS" icon="apple">
		```bash
		brew tap spxrogers/tap
		brew install agentsync
		```

		<Aside type="caution" title="Raw-archive downloads on macOS">
			The Homebrew cask above needs no extra steps. If you instead download a raw
			release archive, note the prebuilt macOS binaries are **not signed or
			notarized**, so Gatekeeper blocks the first run (*"the developer cannot be
			verified"*). Clear the quarantine attribute before running it:

			```bash
			xattr -dr com.apple.quarantine ./agentsync
			```
		</Aside>
	</TabItem>
	<TabItem label="Windows" icon="seti:windows">
		Scoop:

		```powershell
		scoop bucket add spxrogers https://github.com/spxrogers/scoop-bucket
		scoop install agentsync
		```

		Chocolatey:

		```powershell
		choco install agentsync
		```
	</TabItem>
	<TabItem label="Linux" icon="linux">
		Pick the package for your architecture — both `amd64` and `arm64` are
		published every release (use the matching URL).

		Debian / Ubuntu:

		```bash
		# amd64
		curl -fsSL https://github.com/spxrogers/agentsync/releases/latest/download/agentsync_linux_amd64.deb -o agentsync.deb
		# arm64
		curl -fsSL https://github.com/spxrogers/agentsync/releases/latest/download/agentsync_linux_arm64.deb -o agentsync.deb
		sudo dpkg -i agentsync.deb
		```

		RPM:

		```bash
		# amd64
		sudo rpm -i https://github.com/spxrogers/agentsync/releases/latest/download/agentsync_linux_amd64.rpm
		# arm64
		sudo rpm -i https://github.com/spxrogers/agentsync/releases/latest/download/agentsync_linux_arm64.rpm
		```

		Arch (AUR) — wired but not published yet
		([issue #13](https://github.com/spxrogers/agentsync/issues/13)); use the
		`.deb`/`.rpm` or prebuilt binary for now:

		```bash
		yay -S agentsync-bin
		```
	</TabItem>
</Tabs>

## npm / Bun (any OS)

Already have Node or Bun? Run agentsync without installing it, or install it
globally. The npm package is **`agentsync.cc`** (`agentsync` on npm is an
unrelated project); the command it installs is `agentsync`.

<Tabs syncKey="js-pm">
	<TabItem label="npm">
		```bash
		npx agentsync.cc --version     # run without installing
		npm install -g agentsync.cc    # install the `agentsync` command
		```
	</TabItem>
	<TabItem label="Bun">
		```bash
		bunx agentsync.cc --version    # run without installing
		bun add -g agentsync.cc        # install the `agentsync` command
		```
	</TabItem>
	<TabItem label="pnpm">
		```bash
		pnpm dlx agentsync.cc --version
		pnpm add -g agentsync.cc
		```
	</TabItem>
</Tabs>

The package is a small Node launcher. The binary itself comes from a platform
package (`@spxrogers/agentsync.cc-<platform>-<arch>`, for linux, darwin, and win32
on x64 and arm64) that your package manager installs as an optional dependency. No install
script runs, so `bunx` and `--ignore-scripts` work. The binaries are the ones
attached to the matching GitHub Release, checked against its `checksums.txt`
before packing, and published with [npm provenance](https://docs.npmjs.com/generating-provenance-statements).

<Aside type="caution" title="Don't omit optional dependencies">
	Installing with `--omit=optional` / `--no-optional`, or from a lockfile made on
	a different OS or CPU, leaves the platform package out. The launcher then
	exits with an error naming the missing package. Reinstall without those.
</Aside>

## From source

Prefer to build it yourself, or want the latest unreleased commit?

```bash
go install github.com/spxrogers/agentsync/cmd/agentsync@latest
```

Or clone and build:

```bash
git clone https://github.com/spxrogers/agentsync
cd agentsync
go build ./cmd/agentsync
```

You'll need Go ≥ 1.26.2 (the version pinned in `go.mod`).

## Verify

```bash
agentsync --version
```

## Run a health check

Once installed, `doctor` confirms your environment is ready — PATH, home and
state writability, config schema, and the secrets backend:

```bash
agentsync doctor
```

<Steps>

1. **Install** the binary (above).

2. **Initialize** your config directory:

   ```bash
   agentsync init
   ```

3. **Continue** to [your first sync](/getting-started/first-sync/).

</Steps>
